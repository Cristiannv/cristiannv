He trabajado con tecnologías como Python, FastAPI, Java, Spring Boot, JavaScript, React, Angular y Kotlin, desarrollando APIs REST, aplicaciones y sistemas orientados a resolver necesidades reales.

Actualmente estoy interesado en oportunidades donde pueda aportar mis conocimientos, asumir nuevos retos técnicos y continuar creciendo como profesional de software.
